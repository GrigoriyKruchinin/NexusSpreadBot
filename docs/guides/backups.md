# Бэкапы базы и проверка восстановления

Бэкап (дамп) - это полная копия данных `nexus` в одном файле. Он хранится вне репозитория, поэтому
его нельзя случайно закоммитить, и он защищён правами доступа.

## Что где лежит
- Файлы: `~/nexus-backups/nexus-<дата-время UTC>.dump` (каталог можно сменить переменной `BACKUP_DIR`;
  внутри репозитория скрипт откажется работать). Права: каталог 0700, файлы 0600.
- Скрипты: `scripts/backup.sh` (дамп), `scripts/backup_prune.sh` (хранение), `scripts/restore_drill.sh`
  (проверка восстановления), `scripts/sql/bootstrap_backup_roles.sql` (одноразовая подготовка ролей).
- Хранение: 7 последних дневных + по одному самому свежему файлу за 4 предыдущие недели.

## Один раз: создать роли (нужно ваше решение)
Скрипт SQL создаёт роль `nexus_ro` (только чтение, для дампа), роль `nexus_test_owner` и базу
`nexus_test` (для проверки восстановления), и убирает у остальных право подключаться к `nexus` по умолчанию.
Пароли не используются: роли работают только через локальный сокет внутри контейнера Postgres.
```bash
docker compose -f docker-compose.local.yml exec -T postgres sh -c \
  'psql -U "$POSTGRES_USER" -d postgres -v ON_ERROR_STOP=1' < scripts/sql/bootstrap_backup_roles.sql
```
Скрипт можно запускать повторно - ничего не сломается.

## Сделать бэкап
```bash
make backup
```
Дамп делается транзакцией только на чтение, сканер не останавливается. Для ежедневного запуска добавьте
в `crontab -e` строку вида `15 3 * * * cd /путь/к/проекту && make backup >> ~/nexus-backups/backup.log 2>&1`.

## Проверка восстановления (restore drill)
```bash
make restore-drill
```
Берёт последний дамп и восстанавливает его **только** в `nexus_test` (любое другое имя скрипт отвергает),
затем сравнивает количество строк в таблицах с боевой базой. В `nexus` скрипт ничего не пишет.
Результат (только числа) записывается в `docs/reports/restore-drill.md`.

## Как восстановить боевую базу при аварии
Автоматически этого не делает ни один скрипт. Сначала остановите сканер, затем попросите разработчика
выполнить восстановление в новую пустую базу и переключить приложение. Не делайте `docker compose down -v`.

## Внешний пульс (heartbeat)
Бесплатный сервис (например healthchecks.io) ждёт запрос после каждого успешного бэкапа и присылает
оповещение, если его нет. Ссылка-пинг - это секрет: положите её в файл `~/.nexus-heartbeat-url` (права 0600)
и задайте `HEARTBEAT_URL_FILE=$HOME/.nexus-heartbeat-url`. В репозиторий и в чат ссылку не вставляйте.
Платный сервис - только с вашего согласия. Пока сервис не подключён, шаг пропускается.

## Копия на другой компьютер
Необязательно и только с вашего согласия. Перед копированием файл шифруется:
`age -r <публичный-ключ> -o файл.dump.age файл.dump` (или `gpg --encrypt`). Незашифрованный дамп
за пределы этого компьютера не отправляйте.

# Как продолжить работу

В VS Code / терминале открой Claude Code в корне проекта и напиши одно слово: **«продолжай»**.
Оркестратор сам прочитает `docs/pipeline/STATE.md` и `todo.md` и пойдёт по следующему шагу.

Другие команды: «статус» (по файлам, ничего не запускает), «пауза», «аудит заново», «что в бэклоге»,
«добавь агента X».

Длинный прогон шагами с чистым контекстом: `./scripts/run-pipeline.sh` (по одному шагу за запуск).

Важно: интеграционные тесты и `docker compose down -v` не запускать вручную на рабочей базе.

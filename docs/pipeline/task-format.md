# Task card (docs/tasks/<stage>/<ID>-<slug>.md, e.g. `m3/S0-pre-soak-gates.md`)

id, stage, owner, complexity (low|medium|high), depends_on, goal (one sentence), context_docs,
acceptance_criteria (measurable), out_of_scope, files_likely_touched, status (todo|in_progress|review|returned|done).
DoD: `make check` green and not worse than baseline, new tests, no secrets in diff, todo.md + card updated, committed.
